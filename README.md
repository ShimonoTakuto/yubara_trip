# 湯原日和

湯原温泉・勝山のスマホ向け旅行ダッシュボード。HTML / CSS / JavaScriptだけで動作し、ビルドや外部フォントの読み込みは不要です。

## 開く

`index.html` をブラウザで開いてください。

スマホから同じWi-Fi経由で見る場合は、このフォルダで次を実行します。

```powershell
python -m http.server 8000 --bind 0.0.0.0
```

PCのローカルIPアドレスを `ipconfig` で確認し、スマホから `http://PCのIPアドレス:8000` を開きます。Windowsのファイアウォール設定によっては、プライベートネットワークでの接続許可が必要です。停止は Ctrl+C。

## 内容を更新

施設情報は `plan.md` の表をもとにしています。表を変更したら以下を実行し、ブラウザを再読み込みしてください。

```powershell
python build_data.py
```

表の列順は「名称・営業時間・火・水・Google マップ」です。宿と宿内温泉のカードは写真・名称・マップリンクのみを表示します。宿内温泉の地図は宿の検索リンクです。

写真は `assets/photos/` に保存し、`photos.json` で施設名と対応付けています。写真を差し替える際は `src`（保存先）・`alt`（説明）・`source`（出典ページ）・`credit`（出典名）・`image`（元画像URL）を更新して、`python build_data.py` を実行してください。写真の出典は各画面末尾から確認できます。

## ファイル

- `index.html`：画面の土台
- `style.css`：スマホ・PCに対応した和風デザイン
- `app.js`：カテゴリ画面・施設カード・画面遷移
- `data.js`：`plan.md` から生成する施設情報
- `photos.json`：施設写真の対応・出典情報
- `assets/photos/`：カード用の施設写真
- `assets/hanzaki.svg`：オリジナルのはんざきイラスト

Google マップ以外の表示には外部通信を使いません。営業情報は今回再調査しておらず、現在の `plan.md` の値を反映しています。

## 旅の家計簿

トップページの家計簿で、品目・金額・支払った人（T または M）を記録できます。合計とそれぞれの支払額を表示し、費用を折半するための精算額を計算します。1円未満の端数は切り上げます。記録はブラウザのローカルストレージに保存され、別の端末とは共有されません。
